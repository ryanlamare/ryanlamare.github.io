User-agent: *
Allow: /

# Everything under /teaching/ carries <meta name="robots" content="noindex,nofollow">
# and is deliberately NOT disallowed here. A crawler has to fetch a page to see
# its noindex; blocking the path instead would leave those URLs eligible to
# appear in results as bare links with no content, which is the opposite of the
# intent. Keeping them crawlable is what actually keeps them out of the index.
#
# None of this restricts access. Anyone with a URL can open anything, and while
# this repo is public every deck's source is on GitHub, which is itself indexed.
# If genuine non-discoverability is ever required, a private repo is the change
# that delivers it — not these lines.
